### Frontend development

The web frontend developed using Node.js and `pnpm`.
Use `fnm` or comparable tools to use manage node versions.

Example setup:

```bash
# Download and install fnm.
curl -o- https://fnm.vercel.app/install | bash

cat .node-version | fnm install

corepack enable pnpm

pnpm install
```
